# Changelog

## 1.0.0 — Initial public release

- Merged the original DnA Techy logo/icon library and follow-up searchable brand update into one maintainable public project.
- Published **43,008 generated/indexed SVG assets** in the initial verified snapshot:
  - 27,090 brand-logo assets
  - 14,007 solid general-icon assets
  - 1,911 regular general-icon assets
- Added broad searchable brand coverage and general solid/regular icon sets.
- Added curated Power BI, Power Automate, Power Query, Power Apps, Dataverse, Power Pages, Google Apps Script and Python vectors.
- Added human-friendly aliases including Power BI/Power Automate naming variants, AWS and GCP/Google Cloud searches.
- Standardized seven SVG presentation variants.
- Added local live-folder search and repository-index search.
- Added CSV and JSON indexes generated from the actual public library.
- Added automated monthly library refresh through GitHub Actions.
- Added public contribution, security, licensing and third-party trademark notices.
