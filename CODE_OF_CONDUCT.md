# Code of Conduct

We want this project to be a useful, professional and welcoming public resource.

Contributors and maintainers are expected to communicate respectfully, focus criticism on the work rather than the person, avoid harassment or discriminatory behaviour, and respect intellectual-property and trademark concerns raised in good faith.

Project maintainers may edit, hide, lock or remove contributions and discussions that are abusive, spammy, unsafe, unlawful, or unrelated to the project.

For sensitive conduct concerns, contact the DnA Techy maintainers privately rather than posting personal information in a public issue.
