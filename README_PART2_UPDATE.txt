MASTER LOGO / ICON LIBRARY — PART 2 UPDATE
==========================================

PURPOSE
-------
This ZIP is designed to be merged into your EXISTING Master_Logo_Icon_Library folder.
It adds exact searchable Power BI / Power Automate / Power Query product vectors and
replaces Search_Icons.html with a LIVE folder scanner.

HOW TO INSTALL
--------------
1. Open your existing Master_Logo_Icon_Library folder.
2. Extract ALL files from this ZIP directly INSIDE that folder.
3. If Windows asks about same-name files, choose REPLACE for Search_Icons.html/scripts.
   Your existing icon SVG files are not deleted.
4. Open Search_Icons.html.
5. First time only: click "Connect Library Folder" and select Master_Logo_Icon_Library.
6. Search examples:
     Power BI
     Power Automate
     Power Query
     Microsoft Excel
     Google Apps Script
     Python

FUTURE FILES
------------
Search_Icons.html now scans the real folder on disk. It is not dependent on a frozen
embedded icon list. Add any future SVG/PNG files into the folders, then press
"Refresh Library" (or reload the page if permission is already granted).

BULK ONLINE UPDATE
------------------
Double-click:
    RUN_Update_All_Online_Logos.bat

It downloads the latest Simple Icons brand collection and creates the SAME seven variants:
    00_Raw_Source
    01_Transparent_Black
    02_Transparent_White
    03_Circle_Blue
    04_Circle_Dark
    05_Rounded_Square_Blue
    06_Rounded_Square_Dark

It also refreshes exact Microsoft Power BI / Power Automate / Power Query vectors from
Microsoft's PowerBI-Icons repository and refreshes the Google Apps Script vector.

The updater can be run again in the future. Matching files are updated; new files are added.
It does NOT intentionally delete unrelated existing files.

IMPORTANT
---------
Brand names/logos can be subject to trademark/brand-usage rules. Keep source/vendor
guidelines in mind for external/commercial use.
