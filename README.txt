MASTER LOGO & ICON LIBRARY
==========================

Purpose
-------
Offline searchable SVG collection for PowerPoint, Word, websites and design work.
No screenshot crops are used in the Font Awesome collections. The glyphs come from Font Awesome Free vector definitions and are exported into clean SVG files.

Collections
-----------
Brand Logos: 495 unique brand icons
General Icons - Solid: 1402 unique icons
General Icons - Regular: 163 unique icons
Total unique searchable icons: 2060

Variants for every icon
-----------------------
00 Raw Source
01 Transparent Black
02 Transparent White
03 Circle Blue
04 Circle Dark
05 Rounded Square Blue
06 Rounded Square Dark

Search
------
1. Open Search_Icons.html in Edge/Chrome and type a name.
2. Or search directly in Windows Explorer because every filename contains the searchable icon/brand name, e.g. github__logo__circle-blue.svg.

PowerPoint
----------
Insert > Pictures > This Device > select SVG. SVG stays sharp at any size.
Transparent Black SVG is easiest to recolor inside modern PowerPoint using Graphics Fill.
