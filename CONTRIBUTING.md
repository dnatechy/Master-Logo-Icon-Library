# Contributing

Thanks for helping improve the DnA Techy Master Logo & Icon Library.

## Good contributions

- Add a missing searchable alias (`powerbi`, `power-bi`, `microsoft-power-bi`, etc.).
- Correct an icon/logo source to a more authoritative vector source.
- Improve `Search_Icons.html` usability.
- Add a missing general icon category/source while preserving licensing.
- Fix broken SVG rendering or naming.
- Improve legal/source attribution.

## Please do not

- Add screenshot crops when a real vector source exists.
- Trace/redraw an official logo by eye and present it as original artwork.
- Remove trademark/license notices.
- Add proprietary assets that cannot legally be redistributed.
- Commit temporary build folders, downloaded ZIPs, caches or editor files.

## Generated files

Most icon folders and `Icon_Index.*` are generated by `tools/build_library.py`. Prefer changing the builder, source mapping or alias logic rather than manually editing thousands of generated files.

## Pull request checklist

1. Explain what changed and why.
2. Link the authoritative source for new brand artwork.
3. Confirm the asset can be redistributed or referenced under its upstream terms.
4. Run `python tools/build_library.py --clean` when practical.
5. Confirm searches work for common human-readable names.
