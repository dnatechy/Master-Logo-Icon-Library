# Security policy

This repository primarily contains static SVG assets, a browser search page and build automation.

If you find a security issue in `Search_Icons.html`, the build workflow, or a maintenance script, please avoid publishing exploit details in a public issue before maintainers have a reasonable chance to review it. Contact the repository maintainers through the DnA Techy GitHub account.

For ordinary broken icons, missing logos, attribution questions or feature requests, use GitHub Issues.
